## CI PR reviewer (GitHub Actions) + workflow conventions
**TL;DR:** Stood up an automated Claude PR reviewer via GitHub Actions, reconciled it with the App's own generated workflows, and pinned the team conventions (branch/PR for code; no GitHub issues).
Tags: #ci #github-actions #workflow #process · Notes touched: [[ci-pr-review]]
Evidence: PR #1 (`1213181`) · PR #2 (app, `a47c793`) · PR #3 (`af56d9b`) · commits d491fd7 · d3327df · branch main

### Decisions
- **Decision:** Automated PR review runs via **`anthropics/claude-code-action@v1`** using the official **code-review plugin** (`/code-review:code-review`) — not a hand-rolled prompt.
- **Decision:** Auth is the **Claude Max OAuth token** (`CLAUDE_CODE_OAUTH_TOKEN` via `claude setup-token`), not an API key. Secret is set on the repo (the App's install flow added it).
- **Decision:** Final workflow set = the App's two (`claude.yml` = @claude assistant, `claude-code-review.yml` = auto reviewer); removed my duplicate `claude-review.yml` (PR #3).
- **Decision:** Adopted the **branch/PR convention for code from now on** (feature branch → PR → squash-merge; never commit code to `main`). First applied via PRs #1/#3.
- **Decision:** **No GitHub issues** — the tracker stays specs + PRs + `/wrap` logs; revisit a board only if non-spec chore/bug flow grows (then hybrid: issues for non-spec work only).

### Findings / remember
- **Finding:** A newly-added `claude-code-action` workflow shows a **green check but SKIPS** (workflow-validation guard requires the file to match the default branch) — it does **not** review its own introducing PR. First real run is the next PR after merge; a green check can mean "skipped" → verify the run log / PR comments.
- **Finding:** `/install-github-app` generated its **own two workflows** (via PR #2), which duplicated my hand-rolled one — running both = double review per PR.
- **Finding:** Squash-merge makes `git branch -d` report "not fully merged" (the branch tip isn't in `main`'s history); use `-D` to delete a squash-merged branch.

### Changes
- Added then refined the reviewer workflow (PR #1: `d491fd7` add, `d3327df` switch to OAuth + plugin), merged; App added `claude.yml` + `claude-code-review.yml` (PR #2); removed duplicate `claude-review.yml` (PR #3, `af56d9b`).
- Pruned all stale merged branches (local + remote); repo back to just `main`, in sync.
