## Architecture baseline captured as ADRs 0003–0007
**TL;DR:** Recorded the five major architecture forks named in CLAUDE.md as Accepted ADRs, each propagated to the docs it touches and added to the wiki index.
Tags: #adr #architecture · Notes touched: [[workflow-harness]]
Evidence: [[wiki/docs/decisions/0003-dotnet-10-lts]] · [[wiki/docs/decisions/0004-modular-monolith-over-microservices]] · [[wiki/docs/decisions/0005-in-memory-vector-store-slice-azure-ai-search-production]] · [[wiki/docs/decisions/0006-react-typescript-frontend-over-blazor]] · [[wiki/docs/decisions/0007-microsoft-foundry-gateway-anthropic-direct-fallback]] · branch main (no PR)

### Decisions
- **Decision:** 0003 — target .NET 10 LTS (supported to 2028-11-14 vs .NET 8/9 EOL 2026-11-10); C# 14; pin via `global.json`.
- **Decision:** 0004 — modular monolith over microservices; strict module seams keep later service-extraction a refactor, not a rewrite.
- **Decision:** 0005 — in-memory cosine vector store for the slice; Azure AI Search the (unbuilt) production path.
- **Decision:** 0006 — React + TypeScript SPA over Blazor; HTTP/JSON boundary + typed client; DTO drift is the accepted tradeoff.
- **Decision:** 0007 — Foundry gateway primary + Anthropic-direct fallback for chat; failover on availability faults (5xx/429/timeout), not request-level 4xx.

### Findings / remember
- **Finding:** 0007 *builds on* (does not supersede) 0002 — scoped to provider topology + failover policy, leaving the port-split rationale to 0002.
- **Finding:** Accepting 0007 closed the open failover-trigger `TODO` in ARCHITECTURE.md — that doc now has zero open TODOs.
- **Finding:** Stated environment facts aren't trustworthy — user said ".NET 9 installed" but the box is on `10.0.108`; verified before writing it into 0003.
